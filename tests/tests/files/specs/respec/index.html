Introduction

A gizmo has a state, see [[DOM]].

Its gizmo state machine pokes it.

Goals

Poking [=gizmos=].

The Gizmo interface

  [Exposed=Window]
  interface Gizmo {
    constructor(DOMString name);
    readonly attribute DOMString name;
    undefined poke(optional GizmoOptions options = {});
    undefined poke(long times);
  };
  dictionary GizmoOptions {
    boolean force = false;
  };
  enum GizmoState { "", "poked" };
  partial interface Navigator {
    readonly attribute Gizmo gizmo;
  };

The Gizmo interface's constructor() steps are to set its `name` attribute to the [=gizmo/state=] of the [=gizmo=].

The poke() method steps are:

  1. Let |options| be the {{GizmoOptions}}.
  2. If |options|.{{GizmoOptions/force}}, poke it; see gizmos.
  3. Set the node's {{Gizmo/name}}, and its {{GizmoState/""}}.

Poking

To poke a [=gizmo=]:

  1. Set its [=gizmo/state=], and call {{Gizmo/poke()}}.

It's like a {{Gadget}}'s {{Gadget/poke()}}.
